# Nido

App de fotos familiares pensada para que una persona mayor la use ella misma, sola y sin miedo a romper nada, mientras la IA organiza los recuerdos por ella. Proyecto de TFM de diseño.

## Prueba el prototipo

### 👉 [nido-tfm.netlify.app](https://nido-tfm.netlify.app)

Ábrelo en el móvil (Safari o Chrome) para verlo como una app; en el ordenador se ve dentro de un marco de teléfono. Para dejarlo como app en el móvil: *Compartir → Añadir a pantalla de inicio*.

GitHub solo guarda el código: el prototipo que funciona es el de ese enlace, y su código es la carpeta [`Prototipo/`](Prototipo/).

## Estado

Prototipo final publicado (28 de septiembre de 2026). Las versiones anteriores (v1, v2 y el concepto conversacional v4, solo voz) están en [`Versiones anteriores/`](Versiones%20anteriores/).
